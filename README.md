# The Beginner's Guide to ORTSOC to Help Students Adapt Quickly into the Program and Accelerate Student Success

**Status:** Still being built. Planned to be finished by December 8, 2026.

# Project Purpose

The purpose of this project is to create a beginners guide and additional documentation for new or returning ORTSOC students. This is to get students familiar with the ORTSOC material so they can adapt quicker into the program. This will outline dashboards, rotations, tools, and any futher necessary features we deem useful for students to know. The project will provide clear and organized documentation in a guide format that is beginner-friendly, detailed instructions for all necessary ORTSOC features, and recommendations for how students can be successful in the program.

## What is ORTSOC

ORTSOC is a program at Oregon State University where students learn to work as real security analysts with help from mentors and professionals in cybersecurity.

## What the Guide Will Include

- An overview of the ORTSOC program
- Info on each of the five rotations
- Guides for the tools ORTSOC uses
- Walkthroughs and demo videos
- Tips for doing well in the program
